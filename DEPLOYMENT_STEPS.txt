📋 PREPARATION (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Push Code to GitHub
────────────────────────────
  $ git add .
  $ git commit -m "Add Render deployment configuration"
  $ git push origin main

Step 2: Create Render Account
──────────────────────────────
  → Go to: https://render.com
  → Click "Get Started for Free"
  → Sign up with GitHub (recommended)
  → Authorize Render to access your repositories

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 DEPLOYMENT (10 minutes)

Step 3: Create New Web Service
───────────────────────────────
  → From Render Dashboard
  → Click "New +" button (top right)
  → Select "Web Service"
  → Click "Build and deploy from a Git repository"
  → Click "Connect" next to your GitHub account
  → Find and select "elocate" repository
  → Click "Connect"

Step 4: Configure Service
──────────────────────────
  Name:           elocate-api
  Region:         Oregon (US West) or closest to you
  Branch:         main
  Root Directory: (leave blank)
  Runtime:        Docker ⭐ (IMPORTANT: Select Docker, NOT Java!)
  Instance Type:  Free ⭐

  Docker Command: (leave blank - uses Dockerfile ENTRYPOINT)

───────────────

Update CORS Configuration
──────────────────────────
  Edit: src/main/java/com/elocate/elocate/config/SecurityConfig.java
  
  Add your Render URL:
  configuration.setAllowedOrigins(List.of(
      "http://localhost:3000",
      "https://elocate-api.onrender.com"
  ));

Update Auth0 Settings
──────────────────────
  → Go to Auth0 Dashboard
  → Applications → Your App → Settings
  → Add to Allowed Callback URLs:
    https://elocate-api.onrender.com/elocate/callback
  → Add to Allowed Web Origins:
    https://elocate-api.onrender.com
  → Save Changes

Set Up Monitoring (Optional)
─────────────────────────────
  → Sign up at https://uptimerobot.com (free)
  → Create new monitor
  → URL: https://elocate-api.onrender.com/elocate/actuator/health
  → Interval: 5 minutes
  → This prevents cold starts!
